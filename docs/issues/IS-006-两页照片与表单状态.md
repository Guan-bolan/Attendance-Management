# IS-006 每日录入 / 批量登记：双照片、拖入归属日期、点击放大、表单保留、导入后清空勾选

状态：**已完成**（2026-11-09；上下班语义的 slot 列另开工单补）
提出人：YG
涉及页面：`Daily.tsx`、`QuickBatch.tsx`、`App.tsx`

---

## 1. 一条记录可挂两张照片（上班 / 下班）

- **每日录入**：一个人最多挂 2 张照片，语义为「上班一张、下班一张」；0/1/2 张都允许
- **批量登记**：选 **2 张合影**（上班合影 / 下班合影，同一天两拨人可能不是同一张图），勾 N 人 → 生成 N 条，**每条都挂这对照片**
- 库里 `entry_photos` 本来就是多对多，**无需改表**；只是界面从「单选一张」放开到「最多两张」
- 照片墙上要能看出哪张是「上班照」、哪张是「下班照」（例如缩略图角标 `上` / `下`）

## 2. 两页都能直接拖入照片，且归属日期 = 你所选的考勤日期

- 拖入 → 照片进照片池 → 该照片的归属日期 = **当前选的考勤日期**（不看 EXIF 拍摄时间）
- 库里已有 `photos.taken_at_manual` 字段，标记为「手动指定日期」
- **已在池里（内容相同）的照片拖入时不改日期**，只提示「这张照片已在照片池，日期是 X」
- 拖入后：
  - 每日录入：**自动挂到当前表单的照片位**（有空位就填）
  - 批量登记：进池子并出现在可选列表，**不自动设为合影**
- 一次拖多张：每日录入最多填满两个位；批量登记两张合影位

## 3. 两页照片可点击放大

- 用汇总页已有的 `components/ImageViewer.tsx`（滚轮缩放、拖动、双击、用系统看图打开）
- 两处都要：① 照片墙缩略图 ② 记录列表里已挂的照片
- 批量登记页：点开的是「当前选中的合影」

## 4. 切换导航后表单内容保留

- 现已填但未提交的内容，切到别的页面再回来**不能丢**：日期、工地、工人、时段、出勤、加班、备注、已选照片都要还在
- 做法建议：把两页的表单状态提到 `App`（或一个持久 store），页面卸载不销毁；不要用「每次都重置」的 `useState` 初值
- 提交成功后**清空表单**（与「导入后清空勾选」一致）

## 5. 批量登记导入成功后清空勾选

- 整批成功（单事务提交）→ 清空工人勾选；**其它字段全部保留**（日期/工地/时段/出勤/加班/照片），方便接着录下一批
- 整批失败（回滚）→ **保留勾选**
- 顶部保留「已生成 N 条」提示，**不加**「勾选已清空」这类额外文字

## 6. 批量导入后每条记录可单独编辑

- 导入结果列表里每条可编辑：**时段、出勤、加班、备注、照片、工人**（录错人也能换）
- 改完**直接更新那条记录**（不重新生成、不产生第二条）
- 改成与已有记录同键（同人同日同工地同时段）→ 拒绝并提示

## 验收

- [ ] 每日录入能挂 2 张照片，角标区分上/下班；只挂 1 张或不挂也正常
- [ ] 批量登记能选 2 张合影，生成的 N 条记录每条都有这 2 张
- [ ] 拖照片进每日录入 → 照片进池、日期=所选考勤日、自动挂上；照片池里能看到且标「手动指定日期」
- [ ] 拖一张已在池里（但日期不同）的照片 → 不改原日期，提示其现有日期
- [ ] 两页的所有照片点击都能放大（可缩放/拖动/调系统看图）
- [ ] 在每日录入填一半 → 切到工资表 → 切回来 → 内容还在
- [ ] 批量登记填一半 → 切走再回来 → 内容还在
- [ ] 批量导入成功 → 勾选清空、其它字段保留；导入失败 → 勾选保留
- [ ] 导入结果里改一条的加班 → 保存后该条更新（不新增），汇总跟着变
- [ ] 导入结果里把工人改成与别人同键 → 拒绝并提示

## 现象

- 结算单页「历史结算单」每条被「时间」列拉高，行高 **655px**
- 归档页「档案柜」每条被「时间」「档案目录」两列拉高，行高 **325 / 655 / 325px**

## 根因（实测，CSS px；本机 dpr = 2）

antd Table 默认 `table-layout: auto`：**没写 `width` 的列要吃「其余列分完后的剩余宽度」**。这两张表里最长的两段文本恰好落在没写 width 的列上：

| 表 | 无 width 列 | 实得宽 | 文本需要 | 结果 |
|---|---|---|---|---|
| 结算单历史 | 时间 `key:'stamps'` | 30 | 405.51 | 逐字折行 ≈44 行 → 655 |
| 档案柜 | 时间 | 30 | 405.51 | 655 |
| 档案柜 | 档案目录 | 100 | 508.61～566.88 | 325 |

实测列宽：历史表 `[59.74, 218.8, 109.67, 298.32, **30**, 179.46]`（合计 896）；档案柜 `[57.09, 197.1, 131.03, 116.41, **30**, **100**, 264.37]`。

**决定性反证**（只改窗口宽，同一份数据）：`innerW 1000/1167 → 时间列 30、行高 655`；`1280 → 139/105`；`1440 → 299/61`；`1600 → 474/41`。

排除：`ellipsis` 钉 fixed（这两表 computed 为 `auto`）、`.ant-table-cell{overflow-wrap:break-word}`、Tooltip/Paragraph、`whiteSpace`、`align`/自定义 render、全局 CSS、横向溢出（`tableW = clientWidth = scrollWidth = 896`）、数据侧（`nowIso()` 无换行）。

## 复现路径

默认窗口 1180×800、缩放 100%（`innerW 1167`、dpr 2）。结算单 → 保存草稿造行 → 历史结算单；归档 → 生成档案 → 档案柜。Console：

```js
const t = document.querySelectorAll('table')[1]
getComputedStyle(t).tableLayout                                  // "auto"
[...t.querySelectorAll('thead th')].map(x => x.getBoundingClientRect().width)
[...t.querySelectorAll('tbody tr')].map(x => x.getBoundingClientRect().height)  // [655,655]
```

判定阈值：行高 > 41 且该列无 width 且 `tableLayout=auto` 且该格 `clientWidth ≤ 所需宽 ÷ 5`。

## 复现率

5/5（历史表 2/2 行 + 档案柜 3/3 行）；窗口拉到 1600 时消失。

## 修复建议（YG 已确认）

1. **结算单历史表**：时间列 `width: 150` + **render 层夹取**（不要用列的 `ellipsis`，会把表格钉成 `fixed`）+ Tooltip；预算 `50+190+100+170+150+150 = 810 ≤ 896`。实测行高 655 → **41**。
2. **档案柜**：时间列加 width + 夹取；**档案目录只显示目录名**、Tooltip 给全路径（省约 380）；**去掉 `Space wrap`**；预算 `46+170+105+85+110+116+264 ≈ 896`。实测行高 325/655 → 61（去掉 wrap 后不再被 Tag 顶第二行）。
3. **时间统一成本地格式** `YYYY-MM-DD HH:mm`：抽 `renderer/src/utils/stamp.ts`，替换结算单与归档两页四处 ISO 原文输出（`Settlement.tsx:431`、`Archive.tsx:426/505` 等）。
4. **B 类 5 处**按同一约定收口：写死 width + 夹取 + Tooltip。

副作用与红线：夹取必须配 Tooltip（否则丢失发放/解锁时间）；声明宽之和必须 ≤896；`fixed` 布局不压缩列宽，窗口变窄或缩放 >100%（容器 896 → 约 714）必定溢出穿卡片（见 `docs/map.md` IS-009 那条）。**不许靠加宽解决**。

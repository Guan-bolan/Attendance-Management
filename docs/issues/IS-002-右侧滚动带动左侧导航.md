## 现象

右侧主内容区上下滚动时，左侧导航栏（工人台账 / 工地 / 设置 / 照片池 / 每日录入 / 批量登记 / 汇总 / 工资表 / 维护）跟着一起滚出视口，不是固定在左边。

## 坐标

- 页面：全局布局（所有页面都受影响）
- 位置：`src/renderer/src/App.tsx:92`、`:93`、`:153`
- 结构：`Layout(minHeight:100vh)` → `Sider(190)` + `Layout` → `Header` + `Content`

## 根因假设

外层 `Layout` 用的是 `minHeight: '100vh'` 而不是固定高度，页面高度随内容撑开，滚动条落在 `body` 上。`Sider` 是文档流里的普通 flex 子项，因此跟着整个文档一起滚，而不是自己固定、只让 `Content` 内部滚。

## 影响范围

- 所有页面（布局是全局的）
- 不影响数据与计算

## 修复建议（二选一，等修的时候定）

1. **外层固定高度 + 内容自己滚**：`Layout` 改 `height: '100vh', overflow: 'hidden'`，`Content` 加 `overflow: 'auto'`。导航天然固定，Header 也固定。
2. **Sider 吸顶**：`Layout.Sider` 加 `style={{ position: 'sticky', top: 0, height: '100vh' }}`。改动更小，但 Header 仍会滚走。

推荐方案 1：Header 里挂着「缺记录」「缺照片」两条提醒，滚走之后用户看不到。

## 复现路径

1. 打开软件，进「每日录入」录够两屏记录（或进「照片池」拖二十张图）
2. 把右侧内容滚到底
3. 观察左侧导航是否跟着上移

3/3（任何内容超过一屏的页面都复现）

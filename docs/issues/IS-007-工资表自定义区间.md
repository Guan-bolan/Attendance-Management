# IS-007 工资表改成自定义日期区间

状态：**已完成**（2026-11-09）
提出人：YG
涉及：`Payroll.tsx`（主体）、`api.ts`（若无 `payroll.range` 需补一行）

---

## 现状

工资表只能按月看（`payroll:month`），但底层 `rangePayroll(db, from, to)` 本来就支持任意区间，且 `payroll:range` 通道已存在。

## 要改

1. 顶部从「月份选择」改成**起止日期**（原生 `date` 输入，与汇总页一致）
2. **保留快捷**：本月 / 上月 / 本年
3. 默认区间 = **本月**
4. 与「结算单」的分工不变：
   - 工资表 = 随时看应发（不扣预支、不锁定）
   - 结算单 = 真要发钱时用（扣预支、可标记已发放并锁定）
5. 导出的文件名带起止日期（如 `工资表_2026-10-01_2026-10-31.xlsx`），sheet 内表头注明区间

## 验收

- [ ] 工资表页可选任意起止日期，出数正确
- [ ] 「本月 / 上月 / 本年」三个快捷可用
- [ ] 默认进入是本月
- [ ] 选 2026-10-01 ~ 2026-10-31 与按月看 10 月，数字完全一致
- [ ] 导出文件名含起止日期
- [ ] 跨月区间（如 10-15 ~ 11-15）能正常出数，且金额按区间一次取整（口径 19）
- [ ] 界面不出现「分钟」

## 约束

- 不改 `repo/payroll.ts`（`rangePayroll` 已够用）
- 不改金额口径

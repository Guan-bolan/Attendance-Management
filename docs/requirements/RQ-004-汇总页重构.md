# RQ-004 汇总页重构：单对象大日历 + 一行合计 + 浮窗明细 + 导航美化

状态：**已定稿 v4**（2026-11-06；v2 加「全员」，v3 加浮窗看图与图片查看器，v4 收敛为单一滚动区）
日期：2026-11-06
提出人：YG
取代：RQ-002 的界面形态（RQ-002 的「按人/按工地」四视图与并排月历块作废，数据口径继续沿用）

---

## 背景

RQ-002 交付的日历是「四个视图 + 并排月历块 + 横向明细表」，实际用起来三个问题：

1. 两个日历块并排，每块只有半屏宽，格子小、字小，看着累
2. 四个按钮（按人 / 按工地 / 按人·日历 / 按工地·日历）分不清该点哪个
3. 想只看某一个人或某一个工地，没有入口——只能在一屏里找人

## 做什么

### 1. 顶部：三个视图 + 时间 + 对象选择

- 分段控件**三项**：`按人` / `按工地` / **`全员`**
- **时间可自定义**：起止日期选择（默认本月），旁边有「本月 / 上月 / 本年」快捷（三个视图共用这一组）
- **对象单选**（仅前两个视图需要）：
  - `按人`：一个工人下拉（可搜索，同名显示 `姓名 #seq`）
  - `按工地`：一个工地下拉
- 右侧一个「导出」按钮

### 1b. 全员视图：一人一行的合计表

`全员` 不显示日历，显示一张表（复用现有 `summaryByWorker` + `rangePayroll`，**不新写聚合**）：

| 工人 | 工数 | 加班 | 按工地分解 | 应发 |
|---|---|---|---|---|
| 张伟 | 22.50 | 25.5 小时 | 工地A 18.50 工 / 22 小时；工地B 4.00 工 / 3.5 小时 | 8043.75 |

- 表尾可有一行合计（**界面上可以有，导出里不许有**）
- 点某一行 → 切到 `按人` 视图并选中该工人
- 「应发」走 C 路径 + 只入不舍，数值型

### 2. 中间：一个占满整宽的大日历

- **一次只显示一个对象**（一个人或一个工地），月历块**横向占满整个内容区**
- 时间区间跨多个月时，**按自然月纵向分段**：11-15~12-15 就是两个块，区间外的日期灰掉不可点
- 7 列（周一~周日）、每格足够大（建议最小 88×88），日期数字在左上角
- 人视图格子：上行**工数**（大字号），下行**加班**（小字，0 不显示）
- 工地视图格子：上行**出勤人数**，下行**加班合计**
- 周末列浅灰底、今天描边、区间外灰掉
- 纵向滚动（内容多时），**不出现横向滚动**

### 3. 点某天 → 浮窗，不跳页

点任意日期格，弹一个**浮窗**（Modal 或 Popover），内容：

- **人视图**：该人当天每条记录一行 —— `工地 · 时段 · 工数 · 加班 · 备注`，**下方带该条记录挂的照片缩略图**
- **工地视图**：该工地当天每人一行 —— `姓名 · 时长(小时) · 加班(小时)`，**每人下方带照片缩略图**
- 底部一行合计：`当天 3 人 / 3.00 工 / 2.5 小时`
- **点缩略图 → 在浮窗内看原图**（不跳页、不新开窗）
- 浮窗内可关闭；**不做页面跳转**

### 3b. 图片查看器（可缩放/拖动，并能交给系统看图）

现状：照片池点开原图只能固定大小看，不能放大缩小拖动。

做法**两条腿都给**，做成可复用组件 `components/ImageViewer.tsx`：

1. **内置查看器**
   - 初始「适应窗口」；滚轮缩放（以光标为中心，0.2x–8x）；按住左键拖动平移；双击在「适应窗口 / 100%」间切换
   - 工具条：`−` `100%` `+` `复位` `用系统看图打开`
   - 关闭：× 或 Esc
2. **用系统看图打开**：调主进程 `shell.openPath()`，交给 Windows 默认看图程序（可旋转、幻灯片、更顺滑）
   - 通道 `photos:openExternal`，载荷只收 `photoId`（主进程查库拿 `rel_path` 再 `resolveInside` 校验，**不接受任意路径**）
   - 文件不存在 → `E_PHOTO_MISSING`「照片文件不在磁盘上」
   - `shell.openPath` 返回非空字符串即错误信息，原样透传给界面
3. **复用**：浮窗与照片池「点开原图」用**同一个组件**，不写两份

### 1c. 整页只有一个滚动区

**不要出现两层滚动条。** 汇总页固定为三段式，页面本身不滚：

```
工具条（视图切换 + 时间 + 对象 + 导出）   ← 固定
────────────────────────────────────
内容区（日历块 / 全员表）                ← 唯一滚动区（flex:1 + overflow-y:auto）
────────────────────────────────────
底部一行合计                             ← 固定常驻，滚动时也看得见
```

- 根节点 `height:100%; display:flex; flex-direction:column; min-height:0`
- 内容区 `flex:1; min-height:0; overflow-y:auto; overflow-x:hidden`
- 虚拟滚动若需要，**滚动元素必须是这一个**，不许再套一层
- 自检：`document.scrollingElement.scrollHeight === clientHeight`，且全页只有 1 个可滚元素

### 4. 下方：一行合计（不展开明细表）

只显示一行汇总，**不再有逐条明细表**（明细已经在日历格子和浮窗里）：

- 人视图：`张伟 · 2026-11-01 ~ 2026-11-30 · 22.50 工 · 加班 25.5 小时 · **应发 8043.75 元**`
- 工地视图：`工地A · 2026-11-01 ~ 2026-11-30 · 59.50 工 · 加班 32 小时 · 3 人参与`
- 金额沿用现有口径（`rangePayroll`，C 路径 + 只入不舍），点金额可展开算式（复用工资表的 `formula`）

### 5. 导出：弹窗选时间 + 多选对象

点「导出」→ 弹窗：

- 时间区间（默认沿用页面上的）
- 类型：按人 / 按工地
- **多选对象**：工人多选（可搜索）/ 工地的多选，默认勾上当前正在看的那个
- 内容（勾选框）：☑ 汇总 ☑ 明细（至少选一个）
- 导出后打开文件夹

### 6. 左侧导航美化

- 每项加**图标**（工人=用户、工地=工地、照片=图片、录入=编辑、汇总=图表、工资=钱袋、预支=钱包、结算=单据、归档=归档盒、维护=工具、设置=齿轮）
- **分组**：`日常`（每日录入 / 批量登记）/ `台账`（工人 / 工地 / 照片池）/ `统计`（汇总 / 工资表 / 预支 / 结算单）/ `数据`（归档 / 维护 / 设置）
- 当前项：高亮底色 + 左侧 3px 竖条
- 顶部标题区放产品名 + 一个小的「库 vN」状态点
- 不做折叠

## 不做什么

1. 不做逐条明细表（明细在日历格与浮窗里；`全员` 只有一人一行的合计，不是逐条）
2. 不做多对象同时看日历（一次一个）
3. 不做周视图 / 季度视图
4. 不改数据库、不改金额口径、不改汇总聚合逻辑（复用现有 `workerCalendar` / `siteCalendar` / `siteDayDetail` / `summaryByWorker` / `rangePayroll`）
5. 不做主题切换、暗色模式

## 验收标准

- [ ] 顶部有三个分段按钮：`按人` / `按工地` / `全员`
- [ ] `全员` 视图显示一人一行合计表：工人 / 工数 / 加班 / 按工地分解 / 应发；表尾有合计行
- [ ] 点 `全员` 表里的某一行 → 切到 `按人` 并选中该工人
- [ ] 三个视图共用同一组时间区间，切换视图不重置区间
- [ ] 选一个工人 + 2026-11 → 月历占满整宽（1280 窗口下块宽 ≥ 900px），格子 ≥ 88px 高，工数字号明显大于加班小字
- [ ] 1280 宽窗口下**不出现横向滚动条**（页面与日历容器 `scrollWidth === clientWidth`）
- [ ] **整页只有一个滚动区**：页面级不滚（`document.scrollingElement.scrollHeight === clientHeight`），只有内容区可滚
- [ ] 滚动内容区时，顶部工具条与底部合计条**保持不动**
- [ ] 时间选 2026-11-15 ~ 2026-12-15 → 显示两个自然月块，11-15 之前与 12-15 之后灰掉
- [ ] 点 11-03 格子 → 弹浮窗，列出该人当天记录；**页面不发生跳转**（URL/菜单高亮不变）
- [ ] 浮窗里能看到 `工地 · 时段 · 工数 · 加班 · 备注`，底部有当天合计
- [ ] 浮窗里每条记录带照片缩略图；点缩略图在浮窗内看原图（不跳页）
- [ ] 图片查看器：滚轮能缩放、放大后能拖动、双击切换适应窗口/100%、Esc 关闭
- [ ] 「用系统看图打开」能调起 Windows 默认看图程序；照片文件被删时提示「照片文件不在磁盘上」
- [ ] 照片池「点开原图」用的是同一个查看器（行为一致）
- [ ] 切到按工地 + 选工地A → 格子显示人数与加班；点格子浮窗列出当天每人姓名/时长/加班
- [ ] 下方只有一行汇总；人视图显示**应发金额**（附录数据 2026-11 张伟 = 8043.75），点金额能看到算式
- [ ] 按工地视图下方显示工数/加班/参与人数，**不显示金额**
- [ ] 导出弹窗可选时间、可多选工人（或工地）、可勾选汇总/明细；导出的行只含所选对象
- [ ] 导出里金额、工数、时长都是数值型，框选能求和；不含合计行
- [ ] 左侧导航每项有图标、按四组分组、当前项有高亮竖条
- [ ] 300 人 × 31 天下切换工人或月份 ≤ 1 秒

## 约束

- 复用现有聚合：`workerCalendar` / `siteCalendar` / `siteDayDetail` / `rangePayroll`；**不新写第二套聚合**
- 金额只走 `calc.sumAmounts`（C 路径 + 只入不舍）
- 界面不出现「分钟」（口径 22）
- 只读页面，不改数据库

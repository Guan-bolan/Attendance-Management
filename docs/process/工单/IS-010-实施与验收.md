### 1.1 改前到底长什么样（与工单描述不同，见 §5）

- 6 字工地名**没有顶出 12px**：antd 单元格带 `overflow-wrap: break-word`（实测 `getComputedStyle(td)` → `overflowWrap: break-word`、`whiteSpace: normal`），文本直接**折成两行**——截图里是「南湖公园改 / 造」。所以它的 `scrollWidth` 一直等于 `clientWidth`，也从来没压到时段列。
- 折行的代价是**行高多一行 22px**（行高 = 22px 行距 × 行数 + 内边距）。本轮那一行前后都是 83px，因为它的「工数」折算本来就折两行（22×2 + 上下内边距），22px 的行差被更矮/更高的邻居吃掉了；换到本来单行的行上就是实打实的 +22px。
- 「工人 #2」在 80px 列里也是恰好贴边（61.66 / 64），改前不越界；只有 4 字以上姓名 + `#seq` 才超（97.2），超了也是折行。

所以本次修的是**出口本身**：把「折行 / 任意超长」统一改成「单行 + 内容盒内省略 + Tooltip 全文」，跟「时段」列同一套；列宽一个都没动。

## 5. 与要求不一致的地方（3 条，都有读数）

1. **「6 字工地名顶出 12px」不成立。**
   实测：`getComputedStyle(td)` 里 `overflow-wrap: break-word`、`white-space: normal`，6 个汉字（单行自然宽 84 > 内容盒 72）**折成两行**，`lines = 2`、`td.scrollWidth === td.clientWidth = 88`、文本右沿 517 < 时段 left 527。也就是说它从来没压到「时段」列；真正的问题是字形被劈成两行、行高多占 22px（截图 `before-11b-crop-with-header.png`）。
   本次仍然按「夹取 + 省略号 + Tooltip」修，因为要求的一致性（与时段列同一套）和「任意长度都不越界」这两点成立，且不占预算。**列宽没加**。
2. **「工人 `水小文 #2` 顶出」也不成立**：61.66 ≤ 64，本来就是单行贴边。它的风险在 4 字以上姓名（`欧阳水小文 #12` = 97.2），改前会折行，改后被夹住（span 64/97，绘制右沿 431 ≤ 工地 left 439）。按工单场景照样做了验证与截图。
3. **Tooltip 对「没被截断的短名」也会弹**（工地「幸福里」、工人「王芳」悬停也会出提示）：antd `Tooltip` 没有「只在被省略时才显示」的开关，做条件显示得先量文本宽度。这与备注列/时段列的现状一致（备注一直是全量 Tooltip），没有额外成本；若 YG 觉得吵，下一轮可加「量宽度后再决定要不要包 Tooltip」。

## 6. 批量登记同类风险（只报告，未改）

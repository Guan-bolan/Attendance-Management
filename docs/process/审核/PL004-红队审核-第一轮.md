## 一句话结论

**不能进 SDS。** 6 条「会挂」必须先修再下发：**#1**（迁移前快照必抛错 → 所有老库升级启动失败）、**#2**（闸门② 的补救动作被 `createArchive` 堵死 → 区间永久无法清库）、**#3**（补发默认日期落在区间外 → 闸门① 永不归零）、**#4**（闸门① 与结余取整基准不同 → 验收 17 差 1 分）、**#5**（S4 删解锁后归档仍拒 paid → 窗口内归档不可用）、**#6**（拆锁后同 id 改内容清库查不出 → 静默丢改动）。
其余里建议一并修掉：#7/#8/#10/#14/#15/#16/#26（会让用户看到自相矛盾的账或让数据对不上），#9/#11/#12/#20/#21（验收做不出来或页面半套）；#13/#17/#18/#19/#22/#23/#24/#25 可作为 SDS 的补充任务写清判据；#27–#30 记录即可。

## 与生产代码的唯一接触面

- `import ... from '../../../src/main/{ipc,export/xlsx,repo/*,services/paths,db/instance}'`（只读）
- `vi.mock('electron')` 挡掉主进程依赖（与 `src/main/ipc.test.ts` 同一手法），
  然后**直接调 `buildHandlers()` 返回的处理器表**，拿到的就是渲染层收到的那个回包形状。
- 临时库一律 `makeTempDb()`（真文件库 + 真迁移），产物 xlsx 写在 `mkdtempSync` 出来的临时目录，
  用例结束即删。不碰 `out/`、`dist/`、真实数据目录。

## 踩过的坑（别重踩）

1. **`vi.useFakeTimers({ toFake: ['Date'] })`**，不要整套 fakeTimers（exceljs 写盘流永不 finish）。
2. **`getSheetValues()` 的列索引是 `row[c]` 不是 `row[c-1]`**（本台架改用 `getCell(r, c)`，绕开这个坑）。
3. **数金额格别靠口算**：发放 sheet 的结余区标题行 / 子表头行也在同一张 sheet 里，
   扫描区间要从「子表头 + 1」起、到表尾止；明细区到「空行 - 1」止。否则会多扫出 3 个非 number 格。

## 18. 记录表与编辑（2026-11-10 新增）

> 这一区是「每日录入 / 批量登记」两张记录表重构后补的，覆盖编辑、全天列表、照片与工数的显示口径。

### 18.1 记录表（两页同一份组件）

- [ ] 两页的列与列宽**完全一致**（同一常量 `RECORD_COL_WIDTHS`），逐列对比宽度
- [ ] 三档窗口（innerW 1167 / 1280 / 1440）表格都**不出横向滚动**
- [ ] 固定列合计 + 展开列 48 ≤ 848；备注列（唯一自适应）≥ 60
- [ ] 展开行仍能看到「折算过程」与口径来源（继承自全局）

### 18.2 工数列

- [ ] 格子里**只有数字**（如 `1.00`），不含公式文字；单行高度
- [ ] 悬停出 Tooltip，文案与展开行里的折算过程**逐字一致**
- [ ] 数字 `cursor: help`

### 18.3 照片列

- [ ] 0 张 → 显示 `0`，无 `+` 号，行内 `img` 数 = 0
- [ ] 1 张 → `+1`；2 张 → `+2`；4 张 → `+4`；**行内 `img` 数一律 = 0**
- [ ] 4 张照片的行高与 0 张照片的行高**一致**
- [ ] 点 `+N` → 弹窗列出该记录全部 N 张（带「上/下」角标），点任一张能开大图
- [ ] 照片列宽 64，不横向溢出

### 18.4 编辑弹窗

- [ ] 从两页的「编辑」都能打开；标题形如 `改这一条 · #3`
- [ ] **日期是只读文本**（页内 `input[type=date]` 数 = 0），并有「日期不可改」小字
- [ ] 可改：工人 / 工地 / 时段 / 出勤 / 加班 / 备注 / 照片（两个槽位）
- [ ] 保存 = **更新那一条，不新增**（记录数不变，库里对应字段变）
- [ ] 改成与别的记录同键 → 拒绝 + 中文错误文案，且**库里没变**
- [ ] **照片不丢**：造一条 4 张引用（两个 IN、两个 OUT）的记录 → 只改加班保存 → 库里仍是这 4 行、slot 逐个不变
- [ ] 不占槽位的照片在弹窗里有提示「这条还有 N 张照片（未占上班/下班位），保存时会保留」
- [ ] **取消槽位标记** = 该照片从记录摘掉（回到当天照片池，可再从池子挂上）；合并产生的额外照片仍保留
- [ ] 弹窗**不超屏**：`bottom <= window.innerHeight`，`top >= 0`，保存/取消按钮不用滚动就能点
- [ ] 弹窗内**可见纵向滚动容器 ≤ 1**（且只有照片框那一个）；页面级不出现滚动条
- [ ] 弹窗内**无横向滚动**（`.ant-modal-body` 的 `scrollWidth === clientWidth`），逐字段 `right` ≤ 内容右边界
- [ ] 小窗口 800×600：弹窗仍只有 ≤1 根滚动条、按钮可见

### 18.5 批量登记「当天记录」

- [ ] 选日期（还没生成）就显示**当天全部条目**，条数与 `entries:list` 一致；标题 `当天记录 · <日期>`
- [ ] 生成成功后：保留「已生成 N 条」提示；表格是**全天全量**（不止本批）
- [ ] 刚生成的 N 行有**浅黄底高亮**（`#fffbe6`）并滚到可见；高亮保留到下一次操作
- [ ] 批量页能**删除**一行（二次确认，库里少一条）
- [ ] 生成失败仍保留 Alert + 勾选（整批回滚，0 条落库）

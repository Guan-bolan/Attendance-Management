### 10.1 日历式明细 sheet（2026-11-10 新增，v2 版面）

- [ ] 汇总明细导出里出现 `按人日历`；所选对象（按人）导出里出现 `日历`
- [ ] **原有 sheet 全部保留且未变**：`按人明细` / `按工地明细` / `汇总` / `明细` / `照片索引` 的表头与行数与改动前一致
- [ ] 每人占 **4 行**，姓名在左侧**纵向合并 4 行**（读回 `merges` 断言）
- [ ] 四行顺序必须是：**① 上午 ② 下午 ③ 加班 ④ 工地**
- [ ] 第 1 行：有 `上午`/`整天` → `√`；第 2 行：有 `下午`/`整天` → `√`
- [ ] 第 3 行：加班小时（如 `2h`），无加班则空；**不出现「加班」二字**
- [ ] 第 4 行：工地名（多个用 ` / `）
- [ ] 表头日期为 **`MMDD`**（如 `0902`，不带年）；跨月连续（`1231` 后 `0101`）
- [ ] 表尾小注含**完整区间**（如 `区间 2026-09-01 ~ 2026-09-30`）
- [ ] **日期列内容全部 9pt**（`√` / `3h` / `2h` / 工地名），表头 9pt 加粗
- [ ] **列宽**：姓名列按 3 个汉字宽、日期列按 9pt 下 3 个汉字宽（记录实测 `width` 数值）
- [ ] **不换行、不缩字**：`wrapText === false`、`shrinkToFit` 不为 true；名字/工地超 3 字允许溢出
- [ ] **所有单元格居中**（小注左对齐除外）
- [ ] 按小时录入：第 1 行显示时长（如 `3h`）、第 2 行空、第 3 行加班、第 4 行工地
- [ ] 空天四格全空（不是 `0`、不是 `—`）
- [ ] 冻结首行 + 首列
- [ ] 按工地导出**不新增**日历页

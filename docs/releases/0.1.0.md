## 鑫淼考勤 0.1.0

Windows 单机考勤与工资结算工具。给公司人事用：每天在微信群收工人拍照打卡，把照片和工数、加班、工地、日薪餐补记进软件，按月出工资表；发了钱记一笔，随时看每人还差多少；年底按年归档。

单机、离线，不需要装 Node、不需要装数据库、不需要联网。目标机器只要 **Windows 10/11 64 位**。

装好后程序名是 **鑫淼考勤**。两个 exe 用的是同一份程序，数据目录也一样。**不要同时开两个** —— 有单实例锁，第二个会自己退出并激活已开着的窗口。

> 发行包用英文文件名，是为了避开不同浏览器 / 下载管理器对中文文件名的兼容问题。软件本身的界面、菜单、数据目录全是中文。

### 首次运行会被 Windows 拦一下

软件没有做代码签名，首次双击会看到蓝底提示「Windows 已保护你的电脑」。点 **更多信息 → 仍要运行**。

### 安装

**安装版**：双击 → 选安装位置（默认 `%LOCALAPPDATA%\Programs\鑫淼考勤`，装给当前用户，不需要管理员密码）→ 装完自动启动一次。

**绿色版**：放到任意目录双击即可。每次启动会把自己解到临时目录再运行，首次启动比安装版慢 2–5 秒，**不要**放在只读介质（光盘、只读 U 盘）里跑。

## 数据在哪

**唯一位置**：`%USERPROFILE%\Documents\Attendance\`

| 路径 | 内容 | 能不能删 |
|---|---|---|
| `app.db` | 全部业务数据（17 张表，schema v12） | **绝对不能** |
| `snapshots\` | 数据库快照（常规保留 3 份 + 迁移前最多 2 份） | 可删旧的，至少留最近一份 |
| `photos\` | 打卡照片原图（按年月分目录） | 不能删，除非已归档 |
| `thumbs\` | 缩略图缓存 | 可删，会自动重建 |
| `inbox\` | 收件箱，扔进去的照片会被自动吸入 | 可清空 `processed\` |
| `archives\` | 归档档案包 | 不能删 |

**卸载不会删除这个目录** —— 那是几年的考勤和照片。

## 这个版本能做什么

13 个页面，覆盖从收照片到发钱的全流程：

- **工人台账 / 工地** — 姓名 + 日薪 + 餐补一次提交；多段价历史，改价追溯重算；同名软拦；停用/删除（仅限无记录）
- **照片池 / 收件箱** — 拖入即导入，按内容哈希去重，按拍摄日期归位；引用计数；删除二选一
- **每日录入 / 批量登记** — 一行六字段 + 照片槽位（上班/下班）；两张合影 + 勾人一次生成多条（单事务整批回滚）
- **汇总** — 按人/按工地/全员三视图，单对象大日历，点格子看当天明细；导出汇总或明细（可含照片）
- **工资表** — 任意起止区间、多选工人筛选、三项明细与算式、导出 xlsx
- **工资发放** — 结余表 + 发放流水 + 记一笔（凭证照片可多张）+ 当天改/冲销 + 导出对账单
- **预支** — 记预支、冲销、按人累计与可支额度、多凭证、导出
- **归档 / 档案柜** — 生成档案包、22 项校验、打开/重指路径/校验/作废重建/清库（三道闸门）
- **设置 · 维护** — 标准工日、加班折算、餐补默认、快照份数；三个目录可改；界面缩放（14 档 70–200%）；整库备份与恢复

## 钱是怎么算的

这部分是这个软件的命门，写清楚：

**三套单位不混**：时间存分钟、金额存分、工数存 `units_micro`（×10⁶）。数据库里没有一个浮点列。

**金额只入不舍**：基本、加班、餐补三个分项各自精确累加后**向上取整**到分，应发 = 三个已取整分项之和。**永不少给工人一分钱。** 明细展示到元后 3 位，所以「Σ 明细」与「合计」可能差几分 —— 这是有意的，界面会注明。

**结余只有一个公式**：

```
结余 = 上期结转 + 累计应发 − 累计预支 − 累计已发
```

三个累计都只算「日期 ≤ 本地今天」。预支页的「可支额度」和发放页的「还欠多少」读的是同一处实现，不会出现两个页面对不上。

**只增不改**：预支和发放记错了不能删，只能「冲销」记一笔等额负数，原记录留着。当天记错的可以原地改，隔天才发现就得冲销。

## 已知限制

- **只支持 Windows 10/11 64 位**。路径处理、单实例、打包配置都是按 Windows 写的。
- **没有代码签名**，首次运行会被 SmartScreen 拦一次。
- **单机单人**。没有多端同步、没有账号体系，数据在谁的机器上就是谁的。
- **单实例锁**：同时开两个，第二个会退出。

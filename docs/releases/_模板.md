## 下载哪个

| 文件 | 对应 | 适合 |
|---|---|---|
| `xinmiao-attendance-{版本号}-setup.exe` | 安装版（NSIS） | 长期用这台机器。要桌面图标、开始菜单、能从「应用和功能」卸载 |
| `xinmiao-attendance-{版本号}-portable.exe` | 绿色版（免安装） | 拷到 U 盘 / 另一台机器临时用。不写注册表、不建快捷方式 |

装好后程序名是 **鑫淼考勤**。两个 exe 是同一份程序，数据目录也一样。**不要同时开两个** —— 有单实例锁，第二个会自己退出并激活已开着的窗口。

### 升级注意

- **先备份**：装新版之前，打开旧版 → 设置 → 维护 → 「立即备份」，把整库打成一个 zip 放到别处。
- **数据不用搬**：新版会直接读 `%USERPROFILE%\Documents\Attendance\` 里的老数据，会自动升级数据库结构（只加不删）。
- **不要卸载旧版再装**：直接覆盖安装即可。卸载不会删数据，但没必要多这一步。

### 首次运行会被 Windows 拦一下

软件没有做代码签名，首次双击会看到蓝底提示「Windows 已保护你的电脑」。点 **更多信息 → 仍要运行**。

## 数据在哪

**唯一位置**：`%USERPROFILE%\Documents\Attendance\`

| 路径 | 内容 | 能不能删 |
|---|---|---|
| `app.db` | 全部业务数据 | **绝对不能** |
| `snapshots\` | 数据库快照 | 可删旧的，至少留最近一份 |
| `photos\` | 打卡照片原图 | 不能删，除非已归档 |
| `thumbs\` | 缩略图缓存 | 可删，会自动重建 |
| `inbox\` | 收件箱 | 可清空 `processed\` |
| `archives\` | 归档档案包 | 不能删 |

**卸载不会删除这个目录。**

## 已知限制

- 只支持 **Windows 10/11 64 位**
- 没有代码签名，首次运行会被 SmartScreen 拦一次
- 单机单人，没有多端同步、没有账号体系
- 单实例锁：同时开两个，第二个会退出

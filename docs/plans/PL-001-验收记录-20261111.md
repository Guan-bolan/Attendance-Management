## 2. 不通过（2 条）

### 2.1 10.1-12 日历式明细第 4 行 `wrapText=True`（§10.1）

- **现象**：卡要求 `wrapText === false`、超 3 字允许溢出；实现给「工地名」行设了换行。该行行高写死 12pt、列宽 5.15，工地名 ≥4 字会折行并被裁掉。
- **证据**：导出后读 `alignment.wrap_text` → 第 4 行 64 格全 `True`（styles.xml `s=12` 含 `wrapText="1"`）；样本 `C\exp\B-workers-zhangwei-dec.xlsx` 的 `1206` 列 = `南湖公园二期`。
- **位置**：`src/main/export/xlsx.ts:974`（注释坦言故意 wrap）、`:982`（`CALENDAR_SITE_ALIGN`）。

### 2.2 17-1 `dist\` 产物早于源码，且落后一个迁移版本（§17）

- **现象**：产物 11-10 16:13/16:17，源码最新改动 11-11 09:32。
- **更硬的证据**：启动 `dist\win-unpacked\鑫淼考勤.exe` 的日志为 `迁移完成：v0 → v6`、`表（13）`、`87 个通道`；当前源码为 `v7`、`14 表`、`88 通道`（缺 `007_advance_photos`）。CSP 也少一处 `script-src 'self' 'unsafe-inline'`。
- **影响**：安装包不能承载本批代码；用它打开已升到 v7 的库存在不兼容风险。
- **处置**：交付前必须 `打包-最新版.cmd` 重打，并按 D-021 的方式自证「包里有新代码」。

# PL-001 第一批 手动验收卡

> 用途：`WORKFLOW.md` 阶段 8 §第三层（功能与视觉验收）里**必须人工做**的那部分。
> 自动化已覆盖的部分不重复列（单元/集成测试 166 条 + 后续汇总与工资表用例）。
> 用法：从左到右做，通过就打勾；**任何一条不通过就停下来记在最后一行，不要自己解释成「差不多」**。

## 0. 前置准备

1. `cd "E:\Attendance Management"`
2. **用环境变量把数据目录指到临时位置**，不要动真实数据：
   ```powershell
   $env:ATT_DATA_ROOT = "E:\Attendance Management\.tmp\验收一"
   Remove-Item env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
   npm run dev
   ```
   启动日志里应出现 `[db] dataRoot: …\.tmp\验收一（来源：环境变量 ATT_DATA_ROOT）`。
3. 台账建三个工人：张伟（日薪 300、餐补 15、生效 2026-11-01）、王芳（260、15、2026-11-01）、李强（350、无餐补、2026-11-01）；建两个工地：工地A、工地B
4. 准备 30 张 jpg/png 照片（可用手机照片或屏幕截图），放到一个临时文件夹里

> 验收结束删掉 `.tmp\验收一` 即可，真实库全程不参与。
